# PhD Economics Literature Review Lab

An interactive teaching dashboard for a PhD-level Economics Research Methods course. It covers literature-search design, evidence synthesis, chapter architecture, theory and framework selection, Malaysian literature, gap construction, evidence matrices, Gemini Notebook workflows, journal-quality checks, responsible AI use, and editable worksheets.

## Open locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any local static-file server.

## Deployment

The GitHub Pages workflow publishes the contents of `dist` whenever `main` is updated.

## Source notes

The dashboard adapts teaching ideas and examples from the three lecture-note files in the repository root. External claims and current platform instructions are linked to their primary or authoritative sources within the dashboard.
